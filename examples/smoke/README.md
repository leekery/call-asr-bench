# Smoke fixture

This directory contains a tiny **synthetic non-speech** fixture for checking the
`callasr` dataset loader, audio path handling, adapter invocation, metrics, and
JSON artifact plumbing.

The two WAV files are deterministic integer-arithmetic square waves generated by
`generate.py`. They contain no human voice, external recording, dataset sample,
downloaded media, or third-party generated content. The generator and committed
WAV bytes are part of this repository and are covered by the repository MIT
license.

The manifest intentionally includes one Russian (`ru`) and one English (`en`)
item. Its reference text does not describe speech present in the tones. This is
**not a quality benchmark**: WER, CER, and numeric-entity scores from these files
must not be used to compare ASR model quality.

## Reproduce the WAV files

```bash
python examples/smoke/generate.py --output examples/smoke/audio
```

CI regenerates the files in a temporary directory and verifies that their bytes
match the committed fixtures exactly.

## CPU smoke run

Install the local adapter extra:

```bash
uv sync --extra faster-whisper
```

Then run the small multilingual `tiny` model on the fixture:

```bash
uv run callasr run examples/smoke/dataset.jsonl \
  --adapter faster-whisper \
  --model tiny \
  --codec none \
  --device cpu \
  --compute-type int8 \
  --output runs/smoke-tiny.json
```

On first use, faster-whisper will download the selected model weights. The
result only demonstrates that the end-to-end command completes and writes a
valid artifact; the recognition scores are intentionally meaningless.
